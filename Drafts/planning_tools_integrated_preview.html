📐 Architectural Decisions & Exact Implementation Blueprint

Summary of decisions aligned with your feedback and technical modifications planned for index.html and app.js.

1. Saved Route Audits

Maintains full 4-class data ($Y, J, F, C$) with Daily Demand, Audit Fare, Remaining Demand ($R$), and Scheduled Capacity ($C = D - R$).

Includes 1-click “⚡ Zero-Out” transfer and automatic autofill when picking audited routes in Seat Config.

2. Aircraft Comparator in Seat Config

Retains the exact main UI combobox from index.html. Adds a sleek [ ⚖️ Compare ] button right beside [ Browse ].

Clicking it pops up a 3-aircraft comparison panel directly underneath Section 1, recalculating rotation times per plane speed, fleet sizes, and costs.

3. Gap Filler in Route Finder

Removed the standalone tool tab and removed gap filling from Seat Config.

Integrated directly into Route Finder's Active Circuit Timetable as [ ⚡ Fill Remaining ], offering smart multi-leg suggestions and 1-click filter synchronization.
